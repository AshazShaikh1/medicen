# Medicine Expiry Reminder System

## Overview
A web-based system for managing medicine records and reminding users when medicines are approaching expiry.

## Problem
People often manage medicine expiry dates using memory, medicine boxes, or handwritten notes. This can lead to missed expiry dates, expired medicines being retained, and unnecessary wastage.

## Goal
Build a simple, reliable application that lets users:
- Register and log in
- Add, edit, and delete medicine records
- Store medicine name, quantity, batch number, category, and expiry date
- Automatically calculate expiry status
- Identify active, expiring-soon, and expired medicines
- Receive expiry reminders
- Search, filter, and sort medicines
- View a dashboard
- View basic expiry summaries/reports

## Scope
This is an organizational/reminder tool. It must NOT diagnose diseases, recommend treatments, prescribe medicines, change dosages, purchase/deliver medicines, or replace professional medical advice.

## Core Modules
1. User Management
2. Medicine Management
3. Expiry Tracking
4. Reminder & Notification
5. Dashboard
6. Search & Reports

## Main User Flow
Login → Dashboard → Add Medicine → Save → Calculate Expiry Status → Schedule/Check Reminder → Notify User → User manages the medicine.

## Success Criteria
The finished application should be functional, simple to use, responsive, and demonstrable as a student mini project.
